# Bid Wit Me: new background music candidates (round 2, not in the game yet)

Gathered Oct 10, 2026. Nothing here repeats the current 5 tracks (Windows Down, Coins, Final Level, 2 Hour Delay, Chillin Hard).
Every track is CC0 or CC BY (3.0/4.0), so it's free for commercial use in a game. No NC, ND, or SA licenses, and nothing that's "personal use only".

Files:
- Full tracks: `NN-artist-title.mp3` (the original downloads, not re-encoded)
- 30 s previews: `preview-NN-artist-title.mp3` (a strong section, 1 s fade in and out)
- Sampler: `sampler.mp3` (15 s of each track in order 01→12, 1.5 s crossfades, each clip loudness-matched to −16 LUFS, total 2:44)

Measurements: **width** = side/mid RMS ratio and **corr** = L/R correlation, using the same method as round 1 (/tmp/an.py). For reference, the current tracks measured 0.29 (Chillin Hard) to 0.76 (2 Hour Delay). **LUFS** = integrated loudness from ffmpeg ebur128. BPM comes from the incompetech catalog where marked; the others are estimated by analysis (±2, marked ~).
Loudness varies a lot (−8.4 to −17.2 LUFS), so normalize to one target (e.g. −16 LUFS) when tracks go into the game.

## Considered and skipped
- Ghostrifter Official, Purrple Cat, Barradeen, Luke Bergs (on Chosic): CC BY-SA or CC BY-ND, so they're excluded.
- "A cup of tea" (TAD, OGA CC0): its L/R channels are out of phase (corr −0.09), so it would nearly vanish on mono phone speakers.
- "Cat caffe" (TAD, OGA): the file's metadata names a different artist, so its provenance is unclear.
- Pixabay Music: it blocks scripted access (Cloudflare 403), so nothing was pulled from it this round.
- Free Music Archive: downloads now need a login, so it was skipped.
- Holizna "Gamer Beats" Legends / Hard Mode: too energetic and very narrow (width 0.07–0.09).
